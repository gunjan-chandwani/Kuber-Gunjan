# Kuber × Gunjan — Our Little Universe

Deployment-ready static website.

### Secret lock
Default secret code: `kuber` (change `SECRET` in `script.js` to anything you want).

### Features
- Password-style private landing screen
- Romantic responsive design
- Timeline / story
- Photo upload gallery stored locally in the browser
- Surprise animation + floating hearts
- Kuber.exe terminal section
- Personal letter
- Mobile friendly

### GitHub Pages
Upload the files in this folder to the root of `gunjan-chandwani/Kuber-Gunjan`, commit to `main`, then enable Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Expected URL: https://gunjan-chandwani.github.io/Kuber-Gunjan/
